# Kávézó – iskolai projekt

Statikus weboldal (HTML/CSS/JS, build nélkül) egy kávézónak: menü, kosár, **fake** bejelentkezés, online rendelés demo, Revolut Pay opció 5× hűségponttal (szimulált).

Minden adat a böngésző `localStorage`-ában van, nincs szerver, valódi fizetés nem történik.

Helyi futtatás: nyisd meg az `index.html`-t, vagy `python -m http.server`.
